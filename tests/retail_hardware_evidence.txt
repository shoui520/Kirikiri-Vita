# Physical-Vita smoke receipts.

# The host audit cannot prove the Vita renderer, plug-in registry, storage
# timing or modal UI. This file is the only place a hardware result is
# recorded, and the only thing that may promote a title to product-compatible.
#
# id|vpk_sha256|date|status|symptom
#
# status:
#   passed  - the exact VPK reached title, New Game, visible graphics and
#             readable text, and input advanced the scenario.
#   blocked - the exact VPK was run and failed; symptom records what was seen.
#
# A row is evidence about one VPK hash only. Rebuilding invalidates it: the
# gate treats a title with no row for the current VPK as unproven, never as
# working. "-" as a hash means the reporting user did not record one.
#
# Absence of a row is not a negative result. It means no physical run has been
# recorded, which is the default state for most of the corpus.
